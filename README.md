# Biblioteca de Vídeos de Produtos — Unifort (GitHub Pages)

Este repositório hospeda um portal simples (estático) para o time comercial acessar os vídeos de produtos.

## Como publicar no GitHub Pages (rápido)
1. Crie um repositório no GitHub (ex: `biblioteca-videos`).
2. Faça upload destes arquivos na raiz:
   - `index.html`
   - `videos.json`
3. Vá em **Settings > Pages**:
   - **Build and deployment**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
4. Salve. O GitHub vai gerar um link do tipo:
   `https://SEU_USUARIO_OU_ORG.github.io/biblioteca-videos/`

## Como atualizar vídeos
Edite o arquivo `videos.json` e adicione novos itens.

### Links do Google Drive
- **Assistir**: use o link padrão do Drive (view).
- **Baixar**: use:
  `https://drive.google.com/uc?export=download&id=ID_DO_ARQUIVO`

> Dica: se der "sem acesso", é permissão do arquivo/pasta no Drive.
